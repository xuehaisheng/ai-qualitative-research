エージェントは、自分で手順を立て、検索、コードの実行、ファイル操作などの道具を何度も使って、仕事を最後までやるAIである。IBMは “an artificial intelligence system that can accomplish a specific goal with limited supervision” と説明している。

2025年2月のDeep Researchは、自分で何十ものサイトを調べ、出典つきの報告書を書いて持ってくる。この言葉が広く知られるようになったのは、このころからだと思う。同じ月のClaude Codeは、自分でコードを書き、動かし、直す。3月には中国発の汎用エージェントManusが話題になった。

一つのエージェントに大量の作業を任せるより、小さな作業ごとに別のエージェント（サブエージェント）に任せた方が、精度が上がることが多い。一方、ベンジオらは、自分で目標を追うエージェントは途中で自分なりの目標を立ててしまうことがあり、危険だと論じている。

<!--EN-->

An agent is an AI that plans its own steps and uses tools such as search, code execution and file operations again and again to finish a job. IBM describes it as “an artificial intelligence system that can accomplish a specific goal with limited supervision.”

Deep Research, released in February 2025, searches dozens of sites on its own and comes back with a report with sources. I think this is roughly when the word became widely known. Claude Code, released the same month, writes code, runs it and fixes it on its own. In March, Manus, a general-purpose agent from China, drew attention.

Rather than giving one agent a large amount of work, it often works better to hand each small task to a separate agent (a subagent). On the other hand, Bengio and colleagues argue that agents that pursue goals on their own can set goals of their own along the way, which is dangerous.

MCP（Model Context Protocol）は、AIと外部の道具（アプリやデータベースなど）をつなぐための共通の決まりである。2024年11月にAnthropicが公開した。

共通の決まりがあるので、道具の側を一度作れば、いろいろなAIからつなげるようになった。[エージェント]({{ '/literacy/agent/' | relative_url }})が外の世界で作業するための、配線のようなものである。

<!--EN-->

MCP (Model Context Protocol) is a shared standard for connecting AI to outside tools such as apps and databases. Anthropic released it in November 2024.

Because the standard is shared, a tool built once can be connected to many different AIs. It is like the wiring that lets an [agent]({{ '/literacy/agent/' | relative_url }}) work in the outside world.
